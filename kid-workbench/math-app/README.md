# Math App

独立的儿童算数学习前端，包含今日练习、学习地图、加减法与图形探索、四选一练习及结果页。

首页五类题型入口及十二种详情示例读取素材后台发布内容，经 math-server 同源代理。详情与素材、题目后台共用 `packages/math-player`；示例练习不写学习进度。原正式计划练习仍保留，本轮未接入题目后台实时题包。

```bash
npm install
npm run dev
```

- 本地地址：`http://localhost:19142`
- API：开发时由 Vite 代理到 `http://localhost:19141`
- 生产环境：Nginx 将 `/api/` 代理给独立的 `math-server`
- 题目音频：只播放服务端返回的已准备 TTS，不使用浏览器合成或其他音频兜底

## 2026-09-12 题目详情交互

详情使用共享播放器的 `mode="kid"`：题数进度、浅色分区题面、补空回填、答对锁定、点选分类和大号听题按钮。本轮翻题保留答案；退出首页或刷新后重新开始，不写入学习账本。后台默认播放器模式仍兼容旧预览，后台可显式接入儿童模式。

图片字段预留 `example.objectImageUrl`（单个计数物品）及 `example.shapeImageUrls`（图形 key 到 URL）。App 只读取图片，不使用 Emoji/SVG 替代。当前素材发布 Go 契约未提供这些字段，因此数量图、图形题显示素材待准备且禁答；听名称题缺读音时也禁答并隐藏答案文字。需素材端补齐发布契约及实际媒体后再联调，不能把当前状态描述为图片链路已完成。
