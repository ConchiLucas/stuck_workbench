# 孩子知识库

产品主线是：**会了什么 → 错了什么 → 接下来复习什么**。详细约束见[开发文档](../docs/superpowers/plans/2026-09-12-child-knowledge-base.md)，执行验证见[本轮记录](docs/knowledge-base-documentation/progress.md)。

## 首页与明细入口

首页“知识总览”使用九学科积累入口和三张图：能力状态、历史错误、复习状态。明细分别保留在“能力档案”“错题记录”“复习建议”菜单。缺失状态和未细分能力单独标注，不伪装为未练或零掌握。

- **会了什么**：以素材知识目录组织孩子的档案，显示每个知识点各项能力的当前掌握状态。练过算积累；一次答对不等于掌握。未练、练习中、待巩固、已掌握分别显示。
- **错了什么**：全部历史真实错误及提示完成，按知识点、题型查找。优先展示当时的冻结题目、孩子选项与书写笔迹；旧记录缺证据就明确说明，不拿当前素材冒充原题。
- **复习建议**：最近 30 天、最多 20 个可核验实例的分析。把事实和推断分开，重试不当成多个独立样本。保存建议后单独生成草稿，发布、领取和后续真实作答分别追踪。

## 和其他后台的分工

进度后台负责按日、周、月回答“这段时间新学会了什么”。本后台回答“目前哪些能力已掌握，哪些练习出过错”，不复制时间日历、识字矩阵和趋势图。

素材后台负责题目内容、媒体与审核；知识库不编题、配图、配音。题目后台持久化复习建议，校验来源并生成、预览、发布题包；本后台只读学习表，不自行更新掌握度、不代孩子作答。建议与生成命令通过固定题目后台地址转交。

## 数据口径

作答事实只认 `attempts.id`，排除游戏和 `parent_mark`；回执仅补充这次作答，不重复计数。提示作答、独立作答、帮助情况未知分别统计。已有掌握账本仍是能力状态来源，历史明细不完整时保留状态并说明。

科普连线、排序、结构标注按当时保存的配对、完整顺序和标注映射还原；结构化错误事实写明连错了哪条、排出的顺序、各位置放了什么。浏览知识库不记入新的作答。媒体走 `science:` 前缀代理到 science-server 冻结文件，不能拿当前素材或新样题冒充旧题。

逻辑选择类保存稳定选项 ID；排序保存完整序列和即时拒绝的误点。浏览知识库不记入新的作答。媒体走 `logic:` 前缀代理到 **logic-server** 冻结 SVG，不能拿当前素材或新样题冒充旧题。错题筛选学科为逻辑时，能力题型只提供找规律 / 分类 / 排序 / 图形推理 / 找不同 / 比较，不混用识字题型。未关联计划或 live 图未冻结时如实说明，保留对错事实。

成语选择类保存稳定选项 ID（释义 `label:`，成语 `kpId`）。浏览知识库不记入新的作答。媒体走 `chengyu:` 前缀代理到 **task-admin** 冻结 MP3，不能拿当前素材、浏览器朗读或新样题冒充旧题。错题筛选学科为成语时，能力题型只提供听释义 / 选成语 / 看拼音 / 看句子。显示当时题干、孩子选的成语或释义、以及正确答案。未关联计划或 live 读音未冻结时如实说明，保留对错事实。听释义历史播放的是当时冻结的成语读音，不是释义音频。

错题历史不因后来答对而删除。选项位置只有在对应实例中可比较，不能凭“总选第二项”推断语义混淆。一次错误只能说记录过错误；能力缺口必须有真实练习，不能把未练内容说成薄弱。

首版支持完整识字版本回执的复习生成。其他学科保留分析，生成条件不足时给出原因。题包有后续编辑时，显示实际版本差异；不能把其他版本或其他后续练习的成绩直接归因于原建议。

## 服务

目录 `diagnosis-admin/`；Docker `http://localhost:19211`，Vite `:19212`。沿用共享 `study_workbench`。旧接口继续保留，新页面使用 `/api/v1/children/:cid/knowledge`。
