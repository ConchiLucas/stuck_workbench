# 逻辑首页黏土卡 + 第六题型

## 效果

`http://localhost:19192` 做成 2×3 题型画廊，卡片全出血黏土插图（对齐成语卡：草地、泥塑小孩、圆角相框、左下角标题胶囊），不再用纯色渐变 + emoji。

第六题型 **比较** `compare`：大班「哪个更高/更大/更多/更快」，四选一，和分类（哪类不是）找不同（谁和其他不一样）分开。

## 出题

种子新增模块 `compare`，12 个知识点，payload `kind=classify`，沿用现有 `pick1` 出题器。孩子端 `POST /api/v1/logic/quiz/generate` 增加 `type=compare`。失败仍可「用示例题」。

家长看板逻辑学科会多一行「比较」，总知识点 62→74。不改掌握度规则。

## 非目标

不改成语 App。练习页交互保持现有四选一。
