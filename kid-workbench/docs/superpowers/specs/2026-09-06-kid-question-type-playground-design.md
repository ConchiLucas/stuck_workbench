# 四学科孩子端题型试玩设计

## 目标

拼音、科普、英语、算数四个孩子端首页已经是题型画廊。这一轮把它们收成同一种可玩效果：

**点任意一张题型卡 → 直接做完一套题 → 看到对错结果。**

验收地址：

| 学科 | 孩子端 |
|------|--------|
| 拼音 | http://localhost:19112 |
| 科普 | http://localhost:19122 |
| 英语 | http://localhost:19132 |
| 算数 | http://localhost:19142 |

## 最终效果

孩子打开首页，只看到题型卡，没有学习地图、每日计划或详情说明页挡在前面。

点一张卡后：

1. 立刻进入全屏答题，顶栏是关闭、进度（当前 / 总数）、上一题 / 下一题。
2. 一套固定 4 题。选完自动进入下一题；最后一题进入结果页。
3. 结果页列出每一题的对错，提供「再练一次」和「回到首页」。
4. 题型卡本身有黏土插图，标题叠在卡片左下角。

这一轮不写掌握度、不创建每日计划、不改家长看板和内容后台。识字端不在本轮范围。

## 交互契约

四个 App 各自实现，不抽公共包。

| 项 | 约定 |
|----|------|
| 首页 | 全屏题型画廊，一卡一种玩法 |
| 入口 | 卡片是真实链接，点进去就能练 |
| 题量 | 4 题 |
| 选答 | 点选项即作答；正确或错误都记录，约 450ms 后跳下一题 |
| 须先听再选 | 仅拼音「看形认读」「声韵拼读」：选项先播放，听过才能选 |
| 结果 | 答对 n / 4，逐题对照，再练一次会清掉本次作答并重新出题 |
| 失败 | 出题失败只显示一句孩子能懂的话和「再试一次」，不露 JSON / HTTP |

## 各学科题型和出题来源

### 拼音星球

| 卡 | 路由 | 出题 |
|----|------|------|
| 听音选字母 | `/practice/type/listen` | `POST /api/v1/pinyin/quiz/generate` |
| 字中找拼音 | `/practice/type/inword` | 同上 |
| 看形认读 | `/practice/type/shape` | 同上 |
| 声韵拼读 | `/practice/type/blend` | 同上 |

进入一套练习时连续生成 4 道、排除已用 `targetId`。音频走 `/api/v1/pinyin/items/:kpId/speech/...`。浏览器 TTS 只作音频失败时的兜底。

本机 `POST http://127.0.0.1:19111/api/v1/pinyin/quiz/generate` 已能返回题目。孩子端若仍提示「服务返回了无法识别的内容」，按非 JSON 响应处理（常见原因是容器里的前端或路由落后于源码），并重建 `pinyin-app` / `pinyin-server`。

### 小小发现局

| 卡 | 路由 | 出题 |
|----|------|------|
| 选择题 | `/question-types/choice` | 本地 `practiceQuestions` |
| 连线题 | `/question-types/match` | 本地 |
| 排序题 | `/question-types/sequence` | 本地 |
| 结构标注题 | `/question-types/label` | 本地 |

每种已有多题本地库。补结果页 `/question-types/:slug/result`。最后一题的「完成」改为进入结果，不再直接回首页。

### 单词乐园

| 卡 | 路由 | 出题 |
|----|------|------|
| 听音选词 | `/types/audio-choice` | 本地 `questionDemos` |
| 看图选词 | `/types/image-text` | 本地 |
| 组句子 | `/types/card-builder` | 本地 |
| 写单词 | `/types/input-gap` | 本地 |
| 读一读 | `/types/reading-qa` | 本地 |

五种脚本、结果页和卡片图已经存在。本轮只做浏览器走查；缺自动跳题或结果不准再补，不改题型清单。

### 算数乐园

首页已是五张卡，源码里有 `public/cards/{equation,story,missing,judge,shape}.png`。运行中的 Docker 镜像若是旧构建，卡片会是白底。本轮把五张卡都改成直接练习，不再先打开说明详情。

| 卡 | 新练习路由 | 本地玩法 |
|----|------------|----------|
| 看算式选答案 | `/practice/type/equation` | 四选一计算（加减混合） |
| 看数量图选答案 | `/practice/type/story` | 看图数数量，四选一 |
| 补全算式 | `/practice/type/missing` | 选出缺的数字 |
| 判断算式对错 | `/practice/type/judge` | 对 / 错 |
| 认识图形 | `/practice/type/shape` | 看图或听名称选图形 |

旧的 `/types/:typeId` 详情和加法五题原型可以留着，但首页不再链过去。

## 非目标

- 每日计划、掌握度、小红花
- 内容后台出题、TTS、义图
- 识字孩子端
- 把四个前端抽成单仓组件库
- 修复英语 / 算数 `/readyz` 的 MinIO 依赖（不影响本题型试玩）

## 测试

每个改动的 App 先补失败的路由/作答测试，再改页面。收尾时在四个首页上逐张点卡，做完一套并打开结果页。
