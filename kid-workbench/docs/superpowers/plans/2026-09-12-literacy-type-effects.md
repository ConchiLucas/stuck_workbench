# 识字题型效果对齐执行单

本执行单替代原三端统一计划中“App 必须消费后台题目”的要求。App 原首页、直接练习及独立题目组织保持现状；本轮修改两个后台的共享试做组件，不发布或领取任务，不写孩子作答。

## 逐题型基准

| 题型 | App 基准 | 本轮后台调整 |
| --- | --- | --- |
| 看字选义 | 素材字图作题干，四个义图选项，读音按钮在各选项内，反馈在选项上方 | 保持选项音频；对齐反馈位置、正确/错误颜色和图片 contain 规则 |
| 看义选字 | 素材义图作题干，题干旁播放读音，四个字图选项 | 不显示选项读音按钮；不改被冻结的选项数据 |
| 写一写（听音写字） | 隐藏标准字；田字格自由写；旁边播放读音；再听一次／写完了／再写一次 | 对齐按钮、初始/判定中/错误/正确提示；重新试做清空笔迹和反馈 |

## 执行与验收

- [x] 核对 App 原组件及两个后台的数据适配，列出差异。
- [x] 修复看义选字多出的选项播放按钮，添加两端行为回归测试。
- [x] 共享选择题/听写组件按 App 对齐；验证键盘、重复提交、重试及画板重置。
- [x] 对比 App 本地与后台听写判定的共同样本，明确策略差异，不改历史结果或静默降低后台判定门槛。
- [x] 两个后台测试/构建、App 兼容测试、浏览器窄屏和宽屏检查。
- [x] 部署两个后台和使用共享组件的 App 前端，记录效果及明确限制。

尺寸以 App 视觉比例为准，后台按预览容器适配；不把后台整页做成孩子端。题目标题、素材版本等管理信息留在练习区外。标准字形与评分不是本轮可以宣称完全相同的前提，须以样本对比结果为证据。
