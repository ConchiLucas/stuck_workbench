# Math App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an independent iPad-landscape math PWA where a child explores addition, subtraction, and shapes; hears prepared question audio; completes stable two-try practice; resumes interrupted plans; and sees simple results.

**Architecture:** `math-app` is a standalone React project that calls only `math-server` through same-origin `/api/v1`. TanStack Query owns remote state, Zustand owns the local child and unacknowledged answer IDs, a single audio controller enforces one-track playback, and typed visual components render arithmetic or SVG shapes without raw content payloads.

**Tech Stack:** React 19, TypeScript 6, Vite 8, React Router 7, TanStack Query 5, Zustand 5, Tailwind CSS 3, Vitest, Testing Library, Playwright, Nginx, Docker

**Prerequisite:** Complete `2026-09-01-math-server.md` through its API and Docker verification tasks.

}
