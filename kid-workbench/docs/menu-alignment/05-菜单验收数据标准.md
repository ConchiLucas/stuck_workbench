## 交付门槛

1. 从 App **当前路由实际展示**的每个题型详情建立矩阵。逐项填写素材定义、字段、真实媒体、生成器、题包实例、历史快照、具体选择、浏览地址和验证结果。不要把导航入口数或正式掌握技能数当成题型详情数。
2. 素材不足时修改数据契约及代码补齐。素材界面只读浏览/试听/详情；造数脚本通过明确的开发流程准备数据，不恢复生成、编辑、启停等按钮。
3. **题目后台每个实际详情至少 3 道可预览题目**，按入口拆分可识别题包，保证每类都有实际生成/保存实例。数字变式必须运算正确、选项有效；媒体须冻结并逐地址验证字节。分类、听音等特殊交互单独检查。题包列表不是只有 1 道普通题就算完成。
4. **知识库必须有验收数据**：覆盖每个已支持的历史题型，至少正确、错误各一例，错误必须保存稳定选项/具体输入、正确答案、当时快照、媒体来源和时间。分类/书写不能伪装成普通选择题。另准备未练、练习中、待巩固、已掌握等状态；掌握演示值明确说明为模拟账本，不能声称算法验证或真实孩子掌握。
5. 新菜单（下一阶段英语）必须检查 App 的每一种交互在历史适配器中是否支持；不支持则补齐后再造相应数据，不能用别的题型代替，不能仅写“没有真实记录”而交付空页面。算术本轮旧历史只支持四个技能的限制见实例记录，不能把它复制成英语的验收豁免。
6. 使用独立、名称明确包含“验收演示/非真实记录”的孩子；使用唯一批次标记、可重跑脚本和清单。不得 reset 默认真实孩子，不得把模拟数据写到真实孩子账本。若系统事实查询要求 source=quiz，仍须用独立孩子及 client_id 批次标记明确隔离。
7. 进度按时间查这些模拟历史，知识库按知识点/错误查同批记录；展示只读，试听/预览不得追加 attempts。App 暂不对接任务取题，但同型题面组件、媒体和参数必须可复用。
8. 必须测试真实接口 + 页面：列表、展开详情、正确/错选、图片、音频、分类、关闭弹窗、窄屏；媒体不能只看 URL 非空或状态 ready，要请求到有效文件。检查素材服务和消费端是否使用相同存储地址/桶/路径配置。
9. 再运行脚本验证幂等；记录运行前后真实孩子账本校验、演示数据数量、生成任务 ID、演示孩子 ID、截图、清理范围。没有验证的项如实标注，不得以共享组件存在宣称全部完成。

## 后续菜单必须执行：真实生产流程、历史不可变性、演示数据有效性、统计口径（2026-09-14）

英语二次审核后，这四条对后续菜单同样强制。不能只用造数脚本、手工插入完整快照或理想单元测试，声称“真实作答链路 / 历史不可变 / 统计口径”已通过。

### 1. 真实生产流程

1. 合格历史必须来自正常业务接口：创建计划、按展示索引作答、进度/知识库按 **attempt_id** 读取当次记录。
2. 计划生成时就要写入历史渲染所需的完整题面：`schema=1`、kind、完整 example、选项顺序、稳定选项 ID、答案、媒体引用。不得只写 `{code,type}`，再在查看时用最新素材或最新计划补成原题。
3. 每次作答保存当次实际输入（选择题稳定选项 ID；排序保存排句结构；拼写保存输入文本）。同一 `plan_item` 先错再对时，第一次错误记录不得被第二次覆盖。
4. 进度和知识库读取同一次作答的同一份原题与输入，保持只读。展示索引必须映射到稳定选项 ID，不能把累积 `picks` 整份当成当次选择。
5. 验证必须用独立演示孩子走一遍：创建计划 → 同一 item 先答错再答对 → 分别打开两次作答。不能仅手工插入两个完整快照再声称正常流程通过。

### 2. 历史不可变性

1. 验证“素材更新后历史保持不变”时，必须更新 **实际素材源**（知识点 payload、素材表列、对象存储），再确认此前已保存作答的题面、选项顺序、实际输入和媒体摘要不变。
2. **禁止** `UPDATE question_snapshot` 或改历史 attempt 来模拟素材更新。改快照不能证明不可变性。
3. 旧记录无法可靠还原时，页面必须明确说明原因，不得用当前题面冒充。

### 3. 演示数据有效性

1. 只用独立、名称含「验收演示/非真实记录」或同等标记的孩子；不得改真实孩子记录。
2. 合格样例必须时间顺序正确（后续作答不得早于第一次）、媒体可播放、图文与当时选择一致。
3. 故意失效的媒体测试必须单独标记为异常样例，不得混入合格清单。文件名或地址看起来像哈希，不能当成媒体完整性证明。
4. 修复坏数据时：只处理明确属于本轮演示的记录；保留修复前证据并记录修复方式。不要把无效样例改成合格样例后声称“素材更新验证通过”。

### 4. 统计口径

1. **完成率** ≠ **正确率**。不得把 `done_count / target_count` 显示为正确率。
2. 正确率使用实际作答事实，并与任务后台同一口径。当前英语进度约定：
   - 正确率 = 答对题数 / 已作答题数；
   - 未作答不计错误；
   - 同一 `plan_item` 当场重试只计该题最终结果（`plan_items.status`），但每次 attempt 仍按当次输入只读展示。
3. 条形需区分答对、答错、未作答；多学科计划按对应学科的题量分母统计。
4. 正式页面不得写死掌握/学习数字。无记录显示空或 0；读取失败明确提示，不回退假数据。
5. 题型名称必须与当前 App 实际题型和正式技能映射一致，不得继续展示已下线旧题型的假统计。
6. 至少验证：全部完成但有错题不能显示 100%；只做部分题时未作答不算错；无记录孩子不出现伪造掌握数或合成热力；切换孩子和日期时数字随真实记录变化。

## 2026-09-14 历史媒体字节冻结（后续菜单必做）

- 媒体摘要必须来自实际文件字节，不能用 URL、对象键或版本占位值代替 SHA-256。
- 创建历史快照时保存不可覆盖的文件版本；媒体准备失败时不得保存半成品计划。
- 分别验证题面 JSON、当次输入、媒体文件三个维度。隔离测试必须实际替换源文件，并证明源摘要改变、历史图片/音频摘要不变；原端口还需检查两个历史后台代理返回相同冻结文件。
- 旧未冻结历史如实提示，保留作答事实，禁止用当前文件倒填历史。文件缺失或摘要失败不能标记 immutable。
- 英语复用 english_question_task_media，实施与证据见 [英语媒体冻结实施记录](英语媒体冻结实施记录.md)。
