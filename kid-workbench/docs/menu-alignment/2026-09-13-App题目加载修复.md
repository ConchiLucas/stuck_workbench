# 2026-09-13 App 题目加载修复

用户反馈：九个孩子端中多处题目详情为空，短句页显示“出题没有成功，点下面再试一次”；要求恢复题目显示。

## 原因与修改

- 九个 App 的 Nginx 原先在启动时解析后端地址。后端容器替换后，旧 IP 仍被使用，出现连接拒绝及 502。统一使用 Docker DNS（127.0.0.11，10 秒缓存）和变量形式的 API upstream，使地址可运行时刷新。识字已有素材代理保留。
- 拼音、英语、科学、算数服务同时加入项目网络与共享网络，共享网络中存在另一个 postgres 别名。英语查询出现 english_assets 表不存在，拼音加载失败，科学无可用题目。四个服务明确连接 kid-workbench-postgres-1，与已有识字修复保持一致。
- 素材内容、题目生成规则和进度后台不变；没有通过假题或自动选择示例题掩盖错误。
