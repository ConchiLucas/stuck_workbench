## 用户要求及不可改变项

- App + 素材后台 + 题目后台 + 进度后台 + 孩子知识库五端同时交付。不得遗漏题目后台或孩子知识库。
- 对照标准是 **science-app 当前路由真正展示的 4 个首页入口**：choice / match / sequence / label。路由 `/question-types/:slug` 与 `/question-types/:slug/:questionId`。不要把题型说明里的示例名称、未挂载代码当成已实现详情。
- choice 实时取题，失败可回退固定示例；match / sequence / label 本阶段固定示例。已有 live 选择题链路不要退回硬编码。固定示例必须能由素材和题目后台完整表达。
- 不能删减 App 题型迁就后台。缺字段、结构图、栖息地图片时改代码和素材补齐。
- 同题型五端共用 `packages/science-player` 与 `shared-go/sciencecontent`。后台外壳沿用各宿主识字菜单风格。
- 不改 App 首页四卡布局。题目、选项、连线区、排序区、标注图位置以科普 App 实际效果为准。不要把识字/英语 760/800/900 断点套给科普。
- 素材后台只读：搜索、筛选、展开、看图、详情、试听已有音频。禁止生成/重做、编辑保存、导入、启停、审核发布、删除（也不能藏进详情或更多菜单）。
- 题目后台必须从真实科普素材生成并保存四类题及其全部实际详情。不能只手写题包或展示固定 App 样例。精简任务卡片；查看弹窗关闭/Esc/焦点恢复。不要发布状态。预览可本地完成四种交互，不得写学习账本。
- 进度按日、周、月和历史时间看练习、新掌握；详情查看真实作答对应的历史原题。不错因/薄弱点清单。正确率≠完成率；无记录为 0/空；失败明确提示。
- 知识库按知识点/能力看积累、掌握、错误和具体作答。连线、排序、标注显示结构化错误事实。不复制进度日历，不改真实孩子账本。不可还原的历史必须说明原因，不能用当前素材或新样题冒充。
- 四种交互必须是一等公民，不能降级成普通选择题凑覆盖。
- 科学事实优先于过度儿童化。单选题只有一个成立答案；连线仅在题干限定的一一对应时使用；循环/过程题明确起点和判定规则。
- 正常计划生产保存完整历史题面（schema=1）；每次作答保存当次结构化输入并关联题目实例；同题先错后对两次记录分别保留。媒体摘要来自实际字节 SHA-256。冻结表 **`science_question_task_media`**，不要硬编码成 english。代码绘制的结构图保存当时 `diagramKey`+`diagramVersion` 与相对坐标。
- 验收数据：每实际详情至少 3 道已保存题；独立孩子名称含「科普验收演示（非真实记录）」；正确/错误/具体输入；同题先错后对；打乱节点后仍正确映射；媒体缺失；无记录孩子。造数可复跑，不污染真实孩子。
- 只构建本次修改服务，原端口，Compose 指定服务 + `--no-deps`。不整套重启/删数据卷。

## 科学依据（素材内同步）

- 绿叶制造养分：自然界以太阳光为光合作用能量来源。题干限定「在大自然里」，避免与人工光源争议。
- 冰→水：吸收热量（升温）融化。
- 鸭子脚趾间有蹼，划水更有力。
- 鱼类用鳃在水中交换气体。题干问「用鳃在水里呼吸」的动物，金鱼成立。
- 连线动物与环境：题干限定「下面三种动物最常见的生活环境」。青蛙也可生活在池塘等湿地，本题只在给定三项中一一对应。北极熊—冰原、骆驼—沙漠成立。
- 器官与本领：眼—看、耳—听、鼻—闻，小学观察课一一对应，不扩展为脑的综合感觉。
- 食物：题干「最爱吃的」。大熊猫野外食物几乎全是竹子；蜜蜂采集花蜜；长颈鹿取食树叶。不把复杂食物网做成强制 1:1。
- 植物生长：种子→发芽→幼苗。起点是种子。
- 蝴蝶：完全变态含蛹。题干写明「本题不包含蛹」，三步卵→毛毛虫→蝴蝶是教学简化，不是完整生活史。
- 水的变化：冰块受热后冰→水→汽。这是加热路径，不是水循环的唯一起点。
- 植物结构：根在地下吸水；叶在茎上接收阳光；花在植株上部，可结种子。坐标相对图幅，不绑死屏幕像素。
