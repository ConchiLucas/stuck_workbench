本菜单是独立的 `phrase` / 英语短句，不是 english 菜单中的「组句子」。

## 用户要求及不可改变项

- App + 素材后台 + 题目后台 + 进度后台 + 孩子知识库五端同时交付。
- 对照标准是 **phrase-app 当前路由真正展示的 4 个入口**，不要把未挂载旧代码算进覆盖范围。
- App 本阶段允许固定示例知识，不强制接入任务后台取题；已有计划/作答链路不退回硬编码。固定示例必须能由素材和题目后台完整表达。
- 不能删减 App 题型迁就后台。缺字段、图片、读音、场景或对话关系时，改素材代码和数据补齐。
- 素材后台只读浏览、搜索、筛选、展开、详情、试听已有音频。禁止生成/重做、编辑保存、导入、启停、审核发布、删除（也不能藏进详情或更多菜单）。
- 题目后台必须从真实短句素材生成并保存：题型、来源、内容摘要、选项顺序、稳定选项 ID、答案、媒体快照。精简任务卡片；查看弹窗关闭/Esc/焦点恢复。不要发布状态操作。预览可本地试答，不得写入孩子学习记录。
- 进度按日、周、月和历史时间看练习、新掌握；详情查看真实作答对应的历史原题。不错因/薄弱点清单。正确率≠完成率；无记录为 0/空；失败明确提示。
- 知识库按短句知识点/能力看积累、掌握、错误和具体错选。明确显示当时选了什么、正确答案是什么。不复制进度日历，不改真实孩子掌握账本。
- 布局以短句 App 为准：左题干右四选项 2×2；断点是视口 **`max-width:900px` 或竖屏** 单列，不是英语 800px 或算术 760px。禁止后台限宽导致约 929px 桌面变成题目在上。
- 播放按钮只播放音频，不能提交答案。历史只读。
- 整句音频必须读完整目标短句，不能单词音频或浏览器朗读冒充。不用 Emoji/无关图片。
- 正常计划生产保存完整历史题面（schema=1）；每次作答保存当次输入并关联题目实例；同题先错后对两次选择分别保留。媒体摘要来自实际字节 SHA-256；URL/对象键不能冒充摘要。优先复用冻结媒体能力，不要把短句硬编码成 english。
- 验收数据：每实际详情至少 3 道已保存题；独立孩子名称含「短句验收演示（非真实记录）」；正确/错误/具体错选；同题先错后对；不同选项顺序；缺失媒体；无记录孩子。造数可复跑，不污染真实孩子。
- 只构建本次修改服务，原端口，Compose 指定服务 + `--no-deps`。不整套重启/删数据卷。

## 实施记录

开发中持续追加，不在最后只写「已完成」。**测试通过或造数成功不等于用户验收通过。**

### 共享协议与题面

- `packages/phrase-player`：四入口同款题面；视口 900px/竖屏单列；有 `speechUrl` 时 fetch+Audio，无 URL 显示「读音素材暂不可用」，默认不使用 `speechSynthesis`。
- `shared-go/phrasecontent`：`HistorySnapshot` schema=1；`FreezeMedia` 按字节 SHA-256 写入 `phrase_question_task_media`；live 源必须是 `/api/v1/phrase/items/{id}/speech.mp3`。
- `shared-go/mastery`：`SkillsFor(phrase)` 返回 Core 3；`SkillFromQuestionCode` 仍识别 reply；`SkillIsTracked` 允许 reply 入账。

### App / phrase-server

- `PracticePage` 按稳定选项 ID 作答；播放不 POST。首页四卡布局未改。
- 计划 Create：`SnapshotFromLiveQuestion` + `FreezeMedia`（`APP_CONTENT_ADMIN_URL` 有值才冻；失败回滚整笔计划）。GET `applySnapshot`。`GET /api/v1/phrase/task-media/:file`。
- Answer 写 `selected` / `plan_item_id`；同一 item 允许先错后对（两次 attempt）。App 仍自动前进。

### 素材后台

- `phrase_item_speech` 存整句 MP3。页面只读：搜索、分组筛选、展开、详情、试听。无生成/编辑/导入/启停/审核发布/删除。
- PUT `/api/v1/phrase/items/:kpId/speech` 仅给造数脚本，UI 不暴露。
- 详情复用 PhrasePlayer 只读预览四种题面。

### 题目后台

- `phrasetask` 从 `knowledge_points` + 整句音频生成四入口，冻结后保存。精简卡片；查看弹窗关闭/Esc/焦点恢复；无发布。
- 预览可本地试答，不写孩子记录。

### 进度 / 知识库

- 进度按 `plan_item_id` + `attempts.selected` 解码；live URL 不改写成历史代理；`{code,type}` 旧快照提示无法还原。
- 进度代理 `GET /api/phrase/task-media/:file` → task-admin `:19201`。
- 知识库 `decodePhrase` 复用 plan_item join 的当次 selected；错选与正确答案并排；未关联 item / 未冻结媒体单独标失败，不倒填当前素材。
- 矩阵 `skills` 用 `PhraseSkills`（含 reply）；完全掌握 rollup 仍用 Core 3。`I'm fine.` 问与答练习中，Good morning 不完全掌握。
- `ApplyOne` 用 `SkillIsTracked` 写入 reply，避免被 `SkillsFor` 拒成 500。reply 不点亮 KP。

### 媒体与语义

- 32 句整句 MP3：`say` 文本等于 title；样例时长 Good morning 0.73s、Good night 0.68s、How are you? 0.71s、Nice to meet you 1.20s。隔离替换 kp 1197 源文件后历史 sha 仍为 `59acac7f5b6f237b11d5a932cea90837955d34aac425ebaf01a19564c9dfc9ec`。
