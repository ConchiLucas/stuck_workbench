用户截图指出：“算术任务后台的布局不对啊，题目不要在上方，要跟 app 端保持一致，在左侧”。桌面算术题面必须沿用 App 左题目、右选项的结构（共享组件 1:2 列宽）；只有与 App 相同的视口宽度不超过 760px 时采用窄屏上下布局。不能因后台卡片 max-width 或容器查询让桌面预览误进入窄屏排列。此要求适用于全部算术详情，英语等后续菜单也必须验收宿主容器和最终计算布局，不能只查是否引用共享组件。

修复：删除 task-admin/frontend/src/styles/app.css 中遗留的 math-task-player 最大宽度 760px；mathTasks.css 移除触发单列的容器查询，直接继承共享 App 的排列与视口断点，保留 20px 卡片内边距，并分别保持两选项一行、三算式三行的结构。App 页面与数据未修改。

## 2026-09-13 最新审核口径：App 示例内容可暂时固定，五端题面效果必须一致

用户原话：“app端的详情的内容这个阶段知识暂时写死，但是效果要跟四个后台保持一致的”。本阶段允许 App 题型详情使用固定示例知识、数字与选项，不强制切换到题目后台取题；已有素材读取链路无需退回硬编码。固定示例也必须能映射到素材字段及真实媒体，不能用缺素材的占位图宣称齐全。

同题型在 App、素材只读详情、题目预览、进度原题和知识库原题中应使用一致的题面组件、媒体及布局规则，按容器适配。历史仍只读、必须使用当时快照；没有真实记录时不得把固定样题伪装成孩子历史。题目后台真实生成与保存仍属交付范围。素材可以提供只读同款详情，不增加编辑、试答或生成操作。

最新算术审计见 [算术内容与五端一致性审核](算术内容与五端一致性审核.md)。本口径优先于旧文档中将“仅固定示例”直接判为未完成的笼统描述。


## 2026-09-13 最新用户要求：素材界面只保留浏览操作

用户原话：“素材部分不要有操作按钮，比如重做字图，启用/停用这些，读音这些或者查看详情这些可以有”。适用于识字、拼音、趣味算数及后续所有菜单。

- **保留**：播放/试听已有读音、查看图片、查看素材详情，以及搜索、筛选、翻页、展开/收起等浏览操作。
- **移除**：重做/生成字图、生成/重做读音、导入、编辑/保存、启用/停用、审核/发布、删除等改变素材内容或状态的界面按钮。不能移到详情、更多菜单或批量工具栏继续显示。
- 详情是只读展示，试听读取已有音频。缺素材应提示缺失，不以试听、刷新或查看详情为名自动执行重做/生成。
- 本决定调整素材后台的用户界面，不要求删除素材、数据库字段或供其他端使用的接口，也不取消题目后台本身的生成能力。
- 此要求取代旧文档中“素材页提供编辑、审核启停、重做、导入按钮”的安排；旧实施记录保留为历史，不能据此恢复按钮。

本次仅更新文档与验收标准，**尚未修改页面代码或部署**。后续执行 AI 须逐菜单落实并记录验证结果，不得把文档更新标记成界面已完成。

## 迁移到拼音时如何适配

| 规则 | 拼音适用方式 |
| --- | --- |
| App / 题目预览 / 进度原题同款、素材为准、首页不重排 | 直接继承 |
| 组间距大于选项间距、清晰分组、触控目标足够、反馈不跳动 | 继承原则；按实际题干和选项验证具体尺寸 |
| 等大正方形、图片内播放按钮 | 图片选择题可参考；声音题、文字题、四线格、拼读式先记录本题型方案，不强行变成图片卡片 |
| 识字的 64/48/16px 与断点 | 识字看字选义的锁定值。拼音已用自己的 48/32/24，见下一节；不能写成全学科硬性值 |
| 播放与选择分开 | 必须保留拼音实际交互语义，尤其先听再选、音频选项；不能因套用按钮样式改变判题流程 |
| 内容完整可用 | 检查真实音频、字母、声调、四线格和素材字段；不得把浏览器合成音或占位图冒充素材齐备 |
| 历史只读 | 保存当时题目、选项 ID/顺序、所选项和结果；缺快照明确提示，不用当前素材重新生成历史 |

## 每轮执行与交付记录

1. 核对当前代码及其他 AI 的未提交改动，打开本菜单 App 实际入口，逐题型列差异和素材来源。
2. 在菜单档案写清用户要求、继承规则、本题型适配方案、各端修改文件和范围外能力，再实施已授权内容。

4. 同一份内容核对 App、题目预览和进度历史题面；素材端只核对内容及媒体供给，不重新加题型或试做界面。验证加载失败、播放、选择、反馈、切题及适用屏幕；正式提交变更需回归重试与防重复提交，测试不污染真实孩子账本。
5. 仅构建部署受影响服务，原端口、指定服务、--no-deps；遵守根部署要求。
