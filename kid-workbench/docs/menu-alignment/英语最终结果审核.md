## 必须返工的发现

### EN-A01 / P1：组句子、短文没有合格的素材内容来源，任意单词套模板产生错误语义

`task-admin/backend/internal/englishtask/service.go` 的 loadWords 只取有图有音的单词，generate 给任意词套 `This is a/an <word>` 和 `Lucy has a red <word>. She puts it on the table.`。没有词性、可数性或情境约束，更没有读取对应句子/短文素材。

运行题包 3 有 `This is a nine`、`This is a white`；题包 5 有 `Lucy has a red mouth. She puts it on the table.` 和 nose 同款。部分数词表述在特定语境可用，但当前无该语境；white 及把人体部位放桌上的阅读题不适合作为这些普通教学样题。

应在素材层补充可审核的完整句子、词卡、阅读短文、问题、答案及素材关联；生成器只在明确允许的语言和情境规则内变式。不要仅换掉本次几个随机词后保留无约束模板。修复后通过明确批次生成新验收包，保留旧快照出处，不能静默改写历史。

### EN-A02 / P1：组句子播放器播放的是单词音频，不是整句

同文件 card-builder 分支设置 Speech=整句，但 SpeechURL=speech(target)，指向目标单词 MP3。运行题包 3 三题冻结音频字节与素材单词 `/english/words/{targetId}/speech.mp3` 的 SHA256 全部相同。

例：答案句 `This is a rectangle`，播放源却是 rectangle 的单词录音。App 固定示例则通过浏览器 TTS 朗读整句，两端听到的内容不同。

必须提供素材层完整句子音频，冻结与题面文稿一致的文件；验收需检查实际朗读内容，不能只凭 MP3 魔数或 HTTP 200。

### EN-A03 / P1：App 固定示例仍用 Emoji/TTS，素材详情也只覆盖 2/5 题型

`english-app/src/questionDemos.ts` 的 input-gap 使用 🍎 等 cue，reading-qa 使用 Emoji 选项，card-builder 没有素材句音 URL；`QuestionTypePreview.tsx` 一律开启 allowSyntheticSpeech。浏览器访问 `/types/input-gap` 确认显示 🍎。题目后台同类题使用真实图片/MP3，不能据共用 EnglishPlayer 宣称效果一致。允许知识内容固定并不等于允许用不同媒体表现替代素材。

`content-admin/frontend/src/features/english/EnglishPage.tsx` 的 wordSamples 仅返回 audio-choice、image-text。组句子、写单词、读一读没有同款素材详情；其中句子、短文主要在任务后台定义，违背本轮以 App 对照补齐素材能力的要求。

应补齐 5 类素材数据及只读详情，App 固定示例绑定真实素材媒体，后台同型使用同样呈现方式；不要把尚未落实内容写成五端完成。

### EN-A04 / P1：历史按题目 ID 取最新计划项，无法保证还原当次错选

`diagnosis-admin/backend/internal/knowledge/sources.go` 英语分支和 `parent-dashboard/backend/internal/service/english_progress.go` 使用 `ORDER BY pi2.id DESC LIMIT 1`，只按 child/question/kp 关联。相同题后来再练，会使之前的 attempts 配上最新题面/选择。识别 result_conflict 只会标记冲突，不会找回原实例。

现有造数刻意让同一题不混对错，绕开了此问题，不能证明真实历史准确。应建立 attempt 到具体 plan_item/回执的稳定关联；无可靠关联时明确无法还原。需要添加“同一题先错后对、选项顺序不同”的隔离回归场景，不污染真实孩子。

### EN-A05 / P2：任务后台写单词缺少提交和反馈

`EnglishTasksPage.tsx` Preview 没有传 onSettled/completeTo/onAnswer；共享 TypePlay 只有拿到前两者才显示“写好了”。浏览器在第 1 题输入正确答案 cool 后，输入框值为 cool，但 `.kid-write-go` 数量为 0、反馈为空，无法完成与 App 对应的试答过程。组句子的本地判定反馈也应一起检查。

应给任务预览提供独立本地提交/判定反馈，不能为预览增加真实 attempts 写入或要求导航到 App 才能完成。

### EN-A06 / P1（既有问题但影响验收）：进度总览无记录日期仍合成学习次数

`parent-dashboard/frontend/src/pages/Overview.tsx` 的 realisticCalDays 在没有实际记录时生成 attempts/mastered，日详情也有合成 fallback。执行档案已承认它存在，却将该总览作为英语交付入口。

该问题不是本轮英语新增，但其展示不能作为英语真实进度验收通过的证据。真实/演示孩子都应显示对应账本事实，无数据为零或空态；不能把非账本的示意热力混在正式总览。

### EN-A07 / P2：素材版本记录是常量

loadWords 将每个 word.Revision 直接设为 1，任务来源面板却显示为素材版本。媒体冻结摘要是真实的，但这个版本并没有追踪素材内容变化。应记录实际内容修订或内容快照摘要，或准确标注没有版本，而不是展示固定的“版本 1”。
