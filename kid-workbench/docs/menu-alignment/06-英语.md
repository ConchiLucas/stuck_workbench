## 用户要求（本轮，作为后续菜单执行标准）

- App + 素材后台 + 题目后台 + 进度后台 + 孩子知识库五端同时交付，不得跳过题目后台，不得只交空知识库。
- 对照标准是 **英语 App 当前路由真正展示的 5 个题型**，不要把未挂载旧代码（7 套脚本、`sound-discrimination`、`diagnostic-review`）当题型。
- App 本阶段允许固定示例知识，不强制接入任务后台取题；固定示例的数据结构必须能由素材和题目后台表达，未来换数据源仍用同一题面组件。
- 不能删减 App 题型迁就后台；不能用文字、Emoji 或无关占位图冒充应有素材。题目后台生成必须冻真实义图/读音。
- 素材后台沿用识字菜单管理风格：只读浏览、看图、已有音频试听、详情。禁止生成/重做图音、编辑保存、导入、启停、审核发布、删除（也不能藏进详情或更多菜单）。所需素材走开发流程，不以恢复操作按钮代替准备。
- 题目后台必须从英语真实素材生成并保存：题型身份、素材版本、选项顺序、稳定选项 ID、答案及媒体快照。列表精简任务卡片；查看弹窗支持右上角关闭、Esc、关闭后焦点恢复。不要发布状态、状态筛选或发布操作。预览复用 App 同题型组件；试答和试听不得写入孩子学习记录。
- 进度按日、周、月和历史时间看练习、新掌握；原题只读，显示当时保存的题目、选项和媒体。不加入知识库错因/薄弱点清单。
- 知识库按知识点看能力积累、掌握状态、具体错误和实际错选。原题复用同款题面只读。不复制进度日历或识字矩阵。不能把当前素材或新生成样题冒充历史原题。分类/拼写/排序必须保存对应输入结构。
- 布局以英语 App 为准。App 桌面题目在左、选项在右的，后台必须同方向。英语断点是视口 **`max-width:800px` 单列**，不是算术的 760px。禁止后台给预览设 `max-width:760px` 或容器查询，导致约 929px 桌面被切成题目在上。至少验收宽桌面、约 929px、390px。
- 验收数据必交付：每详情至少 3 道已保存题；独立演示孩子，名称含「英语验收演示（非真实记录）」；每种历史交互正确和错误实例；幂等造数；不污染真实孩子。
- 只构建本次修改的服务，原端口，Compose 指定服务 + `--no-deps`。不要整套重启/删数据卷。验证后清理对应旧镜像。
- 此次结果交用户审核；后续改造点写回本档案，作为其他菜单执行标准。

## 五端实现

### 1. 英语 App `:19132`

- 首页粘土五卡布局未改。
- 题面抽到 `@kid-workbench/english-player`。断点 `@media(max-width:800px)` 单列。`allowSyntheticSpeech={!example.speechUrl}`，有素材 URL 时不用浏览器 TTS。
- 听音选词/看图选词可走 english-server live quiz；组句子/写单词/读一读用 `questionDemos` 固定知识，**图片和音频绑定 content-admin 真实素材**（不用 Emoji）。
- 写单词在 App 仍可用 `completeTo` 链接；无 `completeTo` 时预览显示本地「写好了」按钮。
- english-server 代理 `GET /api/v1/english/sentences/:id/speech.mp3`。Compose 仅给 english-server 增加 `APP_CONTENT_ADMIN_URL`。

### 2. 素材后台 content-admin `:19091/english`

- `EnglishPage.tsx`：单词组 + 组句子素材 + 读一读素材。搜索、折叠、试听、查看详情。文案写明不生成、不编辑、不发布。
- 单词详情在同组有足够义图时展示听音选词/看图选词；有对应句子/短文时展示组句子、写单词、读一读。详情题面 `readOnly`。词卡样例使用未过滤分组，避免搜索后只剩一词而缺选项。
- 页面无生成/重做/导入/启停/审核发布/删除按钮。PUT `/english/sentences/:id/speech` 仅供造数脚本灌音，UI 不暴露。
- GET 缺整句音频返回 404，试听路径不合成 TTS。

### 3. 题目后台 task-admin `:19201/english`

- `englishtask`：听音/看图/写单词仍用有图有音单词；组句子只从 `english_sentences`；读一读只从 `english_passages`。无 `This is a/an <word>` / `Lucy has a red <word>` 模板。
- 保存 `sourceTable` / `sourceId` / `sourceContentHash`；不写 `sourceRevision: 1`。来源面板展示内容摘要与媒体摘要。
- 预览可完成本地写单词/组句子试答；`fetch` 仅 GET。`.english-task-player` 无 760px 限宽、无 container query。

### 4. 进度后台 parent-dashboard `:19081`

- `?child=` 写入 `progress-child-id`。英语学科走 `EnglishMastery`（单词卡 + 五项短标记），**不是**识字绿格子。
- 抽屉 `width:min(980px,100vw)`；「查看当时题目」只读 `EnglishHistoryQuestion`。冻结 URL 改写为 `/api/english/task-media/{file}`，backend `TASK_ADMIN_URL` 代理 GET。
- 总览日历按账本事实；无数据日为 0 或「这一天还没有保存的练习记录」，加载失败显示失败。**不再合成空白日热力。**
- 英语历史按 `plan_item_id` + 当次 `attempts.selected` 解码。合格样例是孩子 **5**（正常 `POST /english/plans` + `/answer`）。孩子 4 的 149/174 为修复前无效样例。孩子 3 旧包仍显示无法还原。
- 总览正确率用 `correct_count/done_count`，条形区分答对/答错/未作答。英语题型为听音选词/看图选词/组句子/写单词/读一读，不再渲染「单词认读」或 62/22。

### 5. 孩子知识库 diagnosis-admin `:19211`

- `?child=` 优先。`subject=english` 只给 5 个 App 题型。
- 快照 schema=1：`kind, skillCode, example, selected, responseKind`。choice / order / input 分别保存选项 ID、排句字符串、输入文本。
- 英语 join `pi.id = a.plan_item_id`。无关联时 `unlinked_plan_item`，文案「无法还原作答画面」，不按最新 plan_item 冒充。
- `EnglishEvidence` 只读。合格样例：孩子 5 的 attempt 196/197。孩子 4 的 149/174 为修复前无效样例。孩子 3 旧记录明确无法还原。

共享包：`packages/english-player`、`shared-go/englishcontent`、`shared-go/mastery` 英语技能 listen/picture/build/type/read。
