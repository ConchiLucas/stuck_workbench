# 拼音五端审核清单

对应标准：[五端菜单实施标准](03-五端菜单实施标准.md)。本轮开发后由用户审核，以下未勾选项不能当成验收通过。

## 必查项

- [ ] App 首页四入口保持原样；四题型布局/先听再选/媒体与正式作答不串改。
- [ ] 素材后台拼音沿用识字管理风格，字母/音节仅浏览、试听、只读详情；重做、生成、导入、编辑保存、启用/停用、审核发布按钮均移除，详情/更多菜单无遗漏；没有恢复题型编辑/试答。
- [ ] 题目后台拼音入口可找到；真实生成并保存四题型，刷新后仍为同题和同音频；列表简洁，查看弹窗关闭正常。
- [ ] 进度拼音日期、掌握、字母和音节口径保持；查看当时题目只读、保留原选择、没有现场重出题。
- [ ] 孩子知识库拼音能力/错题入口正常；四题型筛选名称与 App 一致；实际选项/答案按快照展示，旧记录不足明确说明。
- [ ] 各端宽屏/窄屏可用，无横向溢出，音频错误提示清楚，播放失败不能解锁答题。
- [ ] 五端原端口服务可打开，测试和实际验证有证据，未向孩子账本写测试答题。
