| 项目 | 参数 |
| --- | --- |
| 布局 | 左题干、右 2×2 选项；不改成识字正方形图片卡 |
| 组间距 | `--pq-group-gap`：默认 48px；题面宽度 ≤1100px 为 32px；≤760px 或竖屏 24px、改为上下布局 |

| 合成音 | 直播 App `allowSyntheticSpeech`。历史 `false`：缺 URL 显示「读音素材暂不可用」，不用 TTS |
